# Valheim Mods Support

## Français

Bienvenue sur le dépôt de support des mods Valheim de **BenjSammy**.

1. Trouve ton mod dans la liste et clique sur **Ouvrir un ticket**.
2. Garde le nom du mod entre crochets au début du titre, par exemple `[Vehicle Map Markers] Le repère du bateau disparaît`.
3. Choisis **Bug** pour signaler un problème ou **Feature** pour proposer une amélioration. Pour un bug, indique les versions du jeu et du mod, puis les étapes pour reproduire le problème.

## English

This is the support repository for **BenjSammy’s Valheim mods**.

1. Find your mod below and select **Ouvrir un ticket** (open an issue).
2. Keep the mod name in square brackets at the start of the title, for example `[Vehicle Map Markers] Boat marker disappears`.
3. Choose **Bug** for a problem or **Feature** for a suggestion. For a bug, include the game and mod versions and steps to reproduce it.
